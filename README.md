# Розпізнавання таблиць — веб-версія (GitHub Pages)

Статичний фоторедактор таблиць на чистому JavaScript (vanilla JS), без серверної частини.

## Запуск локально

Просто відкрий `index.html` у браузері, або запусти локальний сервер:

```bash
cd web
python3 -m http.server 8080
# відкрий http://localhost:8080
```

## Деплой на GitHub Pages

1. Завантаж вміст папки `web/` у репозиторій (наприклад, у гілку `gh-pages` або в корінь репо).
2. У налаштуваннях репо → **Settings → Pages** обери джерело (гілку/папку `web` або `/root`).
3. Сайт буде доступний за адресою `https://<username>.github.io/<repo>/`.

## Залежності (CDN)

- **OpenCV.js** — `https://docs.opencv.org/4.9.0/opencv.js` (детекція сітки)
- **Tesseract.js** — `https://cdn.jsdelivr.net/npm/tesseract.js@5/dist/tesseract.min.js` (OCR)

Ці бібліотеки завантажуються з CDN, тому для роботи потрібен інтернет.

## Структура

```
web/
├── index.html          # головна сторінка
├── css/
│   └── style.css       # стилі
└── js/
    ├── crop.js         # інтерактивна рамка обрізки
    ├── image-processing.js  # поворот, обробка, детекція сітки (OpenCV.js)
    └── app.js          # головна логіка, OCR (Tesseract.js), експорт
```

## Функціонал (MVP)

1. **Підготовка** — завантаження/демо, поворот 90°/довільний кут, інтерактивна обрізка рамкою.
2. **Комірки** — попередня обробка (нормалізація освітлення), детекція сітки таблиці.
3. **Розпізнавання** — OCR (Tesseract.js) по комірках, ручна корекція проблемних, накладання тексту.
4. **Експорт** — CSV та накладене зображення PNG.

## Примітки

- MVP не реалізує дескев і корекцію перспективи (заглушки) — їх можна додати пізніше через OpenCV.js.
- OCR рукописного тексту (рукописних таблиць) має обмежену точність у браузері.
