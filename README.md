# 📋 Table Lens

**Перетворює фото таблиць на готові дані — CSV для Excel, Sheets чи будь-якої системи.**

Завантаж знімок паперової таблиці, скріншот або скан — і за чотири кроки отримай структуровані дані. Детекція сітки, розпізнавання тексту через Google Gemini, перевірка форматів масками й експорт. Усе працює прямо в браузері.

**[▶ Відкрити застосунок](https://monowan.github.io/table-lens/)** · без реєстрації, без встановлення

## Можливості

### 1. Підготовка зображення

| Функція | Опис |
|---|---|
| **Завантаження файлів** | Кнопка вибору або перетягування зображень у будь-яке місце сторінки |
| **Кілька файлів одразу** | Кожне зображення стає окремим кадром |
| **Назва кадру** | Береться з імені файлу (без розширення), а не «Кадр 1», «Кадр 2» |
| **Демо-зображення** | Одна кнопка генерує тестову таблицю 5×4 |
| **Поворот на 90°** | Вліво та вправо, без втрати якості |
| **Довільний кут** | Слайдер від −45° до 45° з живим перерахунком і показом поточного значення |
| **Обрізка рамкою** | 8 ручок (кути + середини ребер), рамка не виходить за межі зображення |
| **Корекція перспективи** | Розмітка чотирьох кутів документа → вирівнювання трапеції у прямокутник |
| **Повернення до оригіналу** | Скидання всіх трансформацій кадру одним кліком |

### 2. Детекція та редагування комірок

| Функція | Опис |
|---|---|
| **Автоматична детекція** | Пошук замкнених контурів на зображенні, присвоєння рядків і стовпців |
| **Налаштування детекції** | Мінімальна/максимальна площа комірки, розмір ядра морфології, розмір блоку адаптивної бінаризації |
| **Живі слайдери** | Зміна параметра одразу перезапускає детекцію |
| **Нумерація A1, B3** | Кожна комірка підписана за схемою Excel |
| **Вибір комірки** | Клік по комірці → виділення червоною рамкою з кутовими ручками |
| **Редагування геометрії** | Перетягування кутів (довільний чотирикутник) або всієї комірки |
| **Автоматична перенумерація** | Після зсуву комірки рядки й стовпці перераховуються |
| **Малювання вручну** | Кнопка «Малювати» → протягни прямокутник, щоб додати пропущену комірку |
| **Видалення** | Кнопка або клавіша `Delete` / `Backspace` |
| **Обробка освітлення** | Нормалізація яскравості з регульованим рівнем — для фото з тінями |

### 3. Розпізнавання тексту

| Функція | Опис |
|---|---|
| **Google Gemini** | Розпізнавання через API Google AI Studio, модель працює з українською та англійською |
| **Батчинг по рядках** | Комірки одного рядка склеюються в одне зображення — менше запитів, вища швидкість |
| **Прив'язка за ID** | Над кожною коміркою малюється її номер, модель повертає `id:::текст` — переплутати значення фізично неможливо |
| **Обмежувач частоти** | Не більше 9 запитів на хвилину, щоб не впертись у безкоштовний ліміт |
| **Повторні спроби** | При `429` / `503` — автоматичний backoff (1 → 2 → 4 → 8 с), плюс повага до `Retry-After` |
| **Прогрес у реальному часі** | Номер рядка, кількість комірок, назва моделі, розмір запиту в КБ |
| **Розпізнати всі кадри** | Послідовна обробка в пакетному режимі одним натисканням |

### 4. Маски валідації

Маска — набір правил формату для окремих комірок. Дозволяє ловити помилки OCR автоматично.

| Функція | Опис |
|---|---|
| **Візуальний редактор** | Таблиця поверх полотна — виділяй кліком або протягуванням діапазон |
| **Чекбокси класів** | Цифри / Букви / Знаки / Будь-що → автоматична побудова regex |
| **Ручний regex** | Для складних форматів: `\d{2}\.\d{2}\.\d{4}` для дат |
| **Перевірка на повну відповідність** | Вираз звіряє значення від початку до кінця — `\d{2}` не пропустить `1234` |
| **Заміни символів** | Автоматичне виправлення типових помилок OCR: `O→0`, `l→1`, `,→.`, `№→N` |
| **Підсвітка порушень** | Комірки, що не відповідають масці, обводяться помаранчевим |
| **Імпорт / експорт JSON** | Збереження масок у файл і перенесення між пристроями |
| **Збереження в браузері** | Маски живуть у `localStorage`, без сервера |

### 5. Корекція результатів

| Функція | Опис |
|---|---|
| **Метрики** | Загальна кількість комірок, розпізнані коректно, проблемні |
| **Список проблемних** | Картка з фрагментом зображення, координатами та полем введення |
| **Тип проблеми** | «порожня» або «не відповідає масці» — з різним оформленням |
| **Інлайн-виправлення** | Введення одразу оновлює накладений текст, `Enter` — підтвердження |
| **Редактор комірки** | Клік по комірці на зображенні → модалка із збільшеним фрагментом |
| **Перерозпізнати комірку** | Точковий повторний запит до Gemini для однієї комірки |
| **Три режими перегляду** | Оригінал / Після обробки / Розпізнаний текст |

### 6. Експорт

| Формат | Опис |
|---|---|
| **CSV** | UTF-8 з BOM — Excel і Numbers відкривають кирилицю без танців. Назва файлу = назва кадру |
| **PNG** | Зображення з накладеним розпізнаним текстом (червоний шрифт із білою обводкою) |
| **JSON маски** | Збереження схеми валідації окремим файлом |

### 7. Пакетний режим

| Функція | Опис |
|---|---|
| **Галерея кадрів** | Мініатюри всіх завантажених зображень під полотном |

### 8. Інтерфейс

| Функція | Опис |
|---|---|
| **Дві мови** | Українська та англійська, перемикання праве в меню налаштувань |

## Технології

| Компонент | Що використовується |
|---|---|
| Мова | Vanilla JavaScript (ES6+), без фреймворків і збірки |
| Комп'ютерний зір | [OpenCV.js 4.9](https://docs.opencv.org/4.9.0/opencv.js) — контури, морфологія, перспективне перетворення |
| Розпізнавання | Google Gemini API (`generativelanguage.googleapis.com`) |
| Стилі | Чистий CSS із змінними, без препроцесорів |
| Локалізація | Власний модуль на `data-i18n` атрибутах |
| Зберігання | `localStorage` для масок і налаштувань |

**Без бекенду.** Жодного сервера, бази даних чи збірки — усе виконується в браузері. Застосунок розгортається як статичний сайт.

## Запуск локально

Потрібен лише Python або будь-який статичний сервер:

```bash
git clone https://github.com/Monowan/table-lens.git
cd table-lens
python3 -m http.server 8090
```

Відкрий [http://localhost:8090](http://localhost:8090).

> `file://` теж працює, але `http://` надійніше — деякі браузери обмежують API для локальних файлів.

### API-ключ для розпізнавання

1. Відкрий [Google AI Studio](https://aistudio.google.com/apikey)
2. Натисни **Create API key**
3. Встав ключ у поле на кроці 3

Безкоштовний тариф дає достатньо запитів для персонального використання. Ключ зберігається лише у твоєму браузері.

## Структура проєкту

```
table-lens/
├── index.html                # розмітка сторінки, 4 вкладки-кроки, модалки
├── css/
│   └── style.css             # оформлення, змінні, адаптивність
└── js/
    ├── app.js                # стан застосунку, кроки, OCR, експорт, меню
    ├── image-processing.js   # поворот, обробка освітлення, детекція сітки
    ├── perspective.js        # корекція перспективи за 4 точками
    ├── crop.js               # інтерактивна рамка обрізки
    ├── cell-editor.js        # вибір, переміщення, малювання комірок
    ├── mask.js               # редактор масок, валідація, заміни
    └── i18n.js               # словники української та англійської
```
