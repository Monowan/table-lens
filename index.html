❓ Підказки по заміні

Часті помилки OCR і як їх виправити:

ЗаписЩо робить
O=0букву «O» → цифра «0»
l=1букву «l» → цифра «1»
І=1кириличну «І» → цифра «1»
,=.кома → крапка (для чисел)
.=,крапка → кома (для чисел)
=пробіл → нічого (видалити пробіли)
- =дефіс+пробіл → нічого (видалити)
№=Nсимвол «№» → буква «N»

Можна кілька рядків — вони застосовуються по черзі згори вниз. Символ = — розділювач «що → на що». Щоб видалити символи, лишіть праву частину порожньою: = або -=.

❓ Гайд по регулярних виразах

Вираз перевіряє значення комірки ПОВНІСТЮ (від початку до кінця). Ось прості шаблони:

ВиразЩо означаєПриклад збігу
\dбудь-яка цифра (0–9)7
\d+одна або більше цифр1500
\d{2}рівно 2 цифри12
\d{4}рівно 4 цифри2024
[a-zA-Z]одна латинська букваA, z
[а-яА-Я]одна кирилична букваІ, я
[A-Z]{2}-\d{3}2 букви, дефіс, 3 цифриAB-123
\d\d\/\d\dцифра-цифра / цифра-цифра15/30
\d{2}\.\d{2}\.\d{4}дата дд.мм.рррр12.05.2024
\d+(\.\d{2})?число, дріб опційно1500, 1500.50
.*будь-що (без обмежень)text

Спецсимволи . + * ? / \ - ( ) у виразі слід екранувати бекслешем: \. — крапка, \/ — слеш, \- — дефіс.
